Syntax & numerical limits (radians)

Use sin, cos, tan, asin, acos, atan, sqrt, abs, exp, ln (natural log), log (base 10), e, pi/π, and theta/θ. Examples: 2sin(t), 2π, 3cos(θ). Use * between named variables. No inequalities, derivatives, complex values, or arbitrary code.

Explicit: x in [−32,32]. Parameter paths: 1,280 steps, finite bounds within ±1000, span ≤128π; start must be defined. Closed paths stop after one loop. Circle buttons set end = start ±2π (standard cos/sin circles); the start field sets the starting angle. Other curves follow start → end.

Implicit: numerical contours on a 0.25-unit grid in [−16,16]², at most 12,000 segments / 128 branches. Small loops, isolated points, repeated-factor zeros and high-frequency features may be missed. Junctions end branches. Discontinuity checks are numerical, not a proof of continuity; paths stop at detected breaks or the arena edge.
